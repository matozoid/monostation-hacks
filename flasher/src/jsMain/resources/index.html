Circuit Mono Station flasher

Unofficial. Flashes a firmware .syx through the unit's bootloader over USB MIDI. The bootloader itself is never written, so a failed update can always be retried.

Tested with Firefox, the supported browser. When you press Flash, Firefox asks for permission to use MIDI devices with SysEx; allow it.

1. Firmware file

2. Flash

Connect the unit by USB and switch it on. The page asks for MIDI access with SysEx, reboots the unit into its bootloader, sends the firmware and checks the version the unit reports afterwards.

  1. Switch the Mono Station off.
  2. Hold Scales + Note + Velocity.
  3. Switch it on, then let go.
