Circuit Mono Station flasher

Unofficial. Flashes modified firmware over USB MIDI. The bootloader is never written, so a failed update can always be retried.

1. Stock firmware

Choose Novation's stock firmware 1.2, monostation-firmware-800.syx; the page builds the modified firmware from it. Any other .syx is flashed as it is.

2. Firmware to flash

Choose the stock file first.

3. Flash

Connect the unit by USB and switch it on. Allow MIDI access with SysEx when asked.

  1. Switch the Mono Station off.
  2. Hold Scales + Note + Velocity.
  3. Switch it on, then let go.
